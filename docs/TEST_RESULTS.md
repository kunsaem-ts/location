# 실기기 테스트 결과 — 위치 측정 앱

기준: `docs/PRD.md` 7절 (v0.2). 각 시나리오를 수행하고 **실측 결과**와 **판정**을 채웁니다.
판정 표기: `PASS` / `FAIL` / `SKIP`(해당 없음). FAIL이면 메모에 화면 문구·현상을 적어 주세요.

## 1. 시나리오 수행 방법 (요약)

| 조건 | 만드는 방법 |
|---|---|
| WiFi 연결 | WiFi ON, 모바일 데이터 OFF (설정 > 연결) |
| LTE 연결 | WiFi OFF, 모바일 데이터 ON. 5G 기기는 설정 > 연결 > 모바일 네트워크 > 네트워크 모드에서 **LTE/3G/2G(자동 연결)** 선택 |
| 5G 연결 | 네트워크 모드를 5G/LTE/3G/2G(자동 연결)로 두고 5G 표시가 뜨는 곳 |
| 야외 | 건물 밖, 하늘이 트인 곳에서 1분 이상 대기 후 측정 |
| 실내 | 창가가 아닌 실내 |
| 오프라인 | 비행기 모드 ON → 위치(GPS)만 다시 ON |
| 위치 서비스 OFF | 설정 > 위치 끄기 (또는 빠른 설정 패널) |
| 권한 거부 | 앱 정보 > 권한 > 위치 > 허용 안 함 (또는 최초 팝업에서 거부) |
| 모의 위치 (Android) | 개발자 옵션 > 모의 위치 앱 선택 후 가짜 GPS 앱 실행 |
| 재설치 초기화 | 앱 정보 > 저장공간 > 데이터 삭제 (권한 요청 이력·저장 결과 초기화) |
