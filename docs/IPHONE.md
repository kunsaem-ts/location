# 아이폰 설치·실행 안내 (iPhone 12 mini 기준)

이 앱은 App Store 앱이 아니라 **홈 화면에 추가하는 웹앱(PWA)** 입니다. 설치 파일 없이 Safari에서 주소를 열고 홈 화면에 추가하면 됩니다.

## 1. 사전 확인 (1분)

| 확인 | 방법 | 기준 |
|---|---|---|
| iOS 버전 | 설정 > 일반 > 정보 > iOS 버전 | **16.4 이상** (iPhone 12 mini는 iOS 17/18 지원) |
| 브라우저 | 반드시 **Safari** 사용 | Chrome·네이버 앱 등에서는 "홈 화면에 추가"가 없거나 위치 권한이 다르게 동작 |
| 위치 서비스 | 설정 > 개인정보 보호 및 보안 > 위치 서비스 | 켜짐 |
| 네트워크 | WiFi 또는 LTE/5G 연결 | 첫 실행 시 지도와 글꼴을 내려받음 |

## 2. 설치 (홈 화면에 추가)

1. Safari를 열고 주소창에 입력: `https://kunsaem-ts.github.io/location/`
2. 페이지가 뜨면 화면 아래 **공유 버튼**(네모에서 화살표가 위로 나가는 아이콘)을 누릅니다.
3. 목록을 아래로 내려 **"홈 화면에 추가"** 를 누릅니다.
4. 이름이 **"위치 측정"** 으로 되어 있는지 확인하고 오른쪽 위 **추가**를 누릅니다.
5. 홈 화면에 "위치 측정" 아이콘(Flutter 로고)이 생깁니다. 이후에는 Safari가 아니라 **이 아이콘으로 실행**합니다.

## 3. 첫 실행

1. 홈 화면 아이콘을 누릅니다. 주소창 없이 전체 화면으로 열립니다.
2. "위치 권한이 필요합니다" 화면에서 **[권한 허용하기]** 를 누릅니다.
3. iOS 팝업 "'위치 측정'에서 사용자의 위치를 사용하려고 합니다"에서 **"앱을 사용하는 동안 허용"** 을 누릅니다. **"정확한 위치"** 가 켜져 있는지 확인합니다(꺼져 있으면 오차가 수백 m가 됩니다).
4. 지도가 나오면 아래 **[측정]** 을 누릅니다. 몇 초 뒤 지도에 회색 점과 오차 원이 찍히고 아래에 좌표·오차반경·연결망·측위 출처·시각이 표시됩니다.
5. **[다시 측정]** 을 누르면 "직전 대비 거리"가 추가로 표시됩니다. 오른쪽 위 시계 아이콘은 최근 결과 목록입니다.

## 4. 아이폰에서 이렇게 보이면 정상입니다

| 화면 | 설명 |
|---|---|
| 연결망: **알 수 없음** | 아이폰 웹앱은 WiFi/LTE를 구분할 수 없습니다(PRD C-4). 비행기 모드일 때만 "없음"으로 바뀝니다. 마커와 오차 원도 이 때문에 항상 회색입니다. |
| 측위 출처 추정: **GPS 추정 (±12 m)** 처럼 오차반경만 표시 | 아이폰은 위치 출처(GPS/WiFi/기지국)를 알려주지 않아 오차반경으로만 추정합니다(PRD C-2). 20 m 이하 GPS, 100 m 이하 WiFi, 그보다 크면 기지국으로 봅니다. |
| 앱을 완전히 닫았다 열면 위치 권한을 **다시 묻는 경우** | iOS 홈 화면 웹앱의 정책입니다(PRD Q-6). 다시 허용하면 됩니다. 저장된 결과 목록은 유지됩니다. |
| 상태 표시줄(시계·배터리) 아래부터 앱이 시작 | 노치와 홈 인디케이터 영역은 비워 두고 그 안쪽에 화면이 맞춰집니다. |

## 5. 문제가 생기면

| 증상 | 조치 |
|---|---|
| "위치 권한이 거부되었습니다" 화면 | 설정 > 앱 > Safari > 위치 → **"묻기"** 또는 **"앱을 사용하는 동안"** 으로 바꾼 뒤 앱을 완전히 닫고 다시 엽니다. (iOS 17: 설정 > Safari > 위치) |
| "기기의 위치 서비스가 꺼져 있습니다" | 설정 > 개인정보 보호 및 보안 > 위치 서비스 켜기 → 앱에서 **[다시 확인]** |
| 지도 영역이 회색이거나 "지도를 불러오지 못했습니다" | 인터넷 연결 확인. 계속되면 Google Cloud 콘솔의 웹 키 리퍼러 제한에 `https://kunsaem-ts.github.io/location/*`가 있는지 확인 |
| "위치를 찾지 못했습니다" (15초 타임아웃) | 창가나 야외로 이동해 다시 측정. 지하·실내 깊은 곳에서는 위치를 잡지 못할 수 있습니다 |
| "이 앱은 HTTPS 주소에서만 동작합니다" | 주소가 `https://`로 시작하는지 확인하고 홈 화면 아이콘을 지운 뒤 2절부터 다시 추가 |
| 글자가 네모(□)로 잠깐 보임 | 한글 글꼴을 내려받는 중입니다. 1~2초 뒤 정상 표시됩니다 |
| 이전 버전이 계속 보임 | 홈 화면 아이콘을 길게 눌러 삭제 → Safari 방문 기록 및 웹사이트 데이터 지우기 → 2절부터 다시 추가 |

## 6. 결과 기록

실측 결과는 `docs/TEST_RESULTS.md` **3절(iPhone)** 표에 적어 주세요. 최소한 다음 4가지만 확인해 주셔도 됩니다.

1. 홈 화면 아이콘으로 전체 화면 실행됨
2. 야외에서 측정 → 오차 20 m 이내, "GPS 추정" 표시
3. 다시 측정 → "직전 대비 거리" 표시
4. 앱을 닫았다 열어도 최근 결과 목록이 남아 있음
